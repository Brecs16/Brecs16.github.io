# STEAM Who? - Indovina il Personaggio

## Descrizione

STEAM Who? è un'applicazione web interattiva che permette all’utente di pensare a un personaggio famoso del mondo STEAM (Scienza, Tecnologia, Ingegneria, Arte e Matematica), mentre il sistema cerca di indovinarlo attraverso una serie di domande.

## Come funziona

1. L’utente sceglie mentalmente un personaggio dalla lista proposta
2. Il sistema fa domande a risposta SÌ/NO
3. In base alle risposte, il numero di possibili personaggi si riduce
4. Alla fine, il sistema indovina il personaggio

## Tecnologie utilizzate

* HTML → struttura della pagina
* CSS → stile e grafica
* JavaScript → logica del gioco

## Struttura del progetto

* `index.html` → pagina principale
* `steamwho.js` → logica del gioco e domande
* `style.css` → stile grafico (se presente)

## Obiettivo educativo

Il progetto ha lo scopo di:

* sviluppare il pensiero logico
* mostrare l’uso degli algoritmi di filtraggio
* far conoscere figure importanti della storia STEAM

## Possibili miglioramenti
